– synchronizeConversations

Method to synchronize conversations with the backend.

- (void)synchronizeConversations

Discussion

Method to synchronize conversations with the backend.

This method will fetch all conversations that the user is a part of. It will also fetch all messages and participants for each conversation.

This method is useful when you want to fetch conversations after setting TwilioConversationsClientProperties’s synchronizeOnStartup flag to false, otherwise call to this method is ignored.
