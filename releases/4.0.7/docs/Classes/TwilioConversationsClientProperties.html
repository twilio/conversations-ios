  commandTimeout

Timeout in milliseconds for commands which SDK sends over network (i.e. send message, join to a conversation, etc). Completion block will be called when timeout is reached.

@property (nonatomic, assign) NSInteger commandTimeout

Discussion

Timeout in milliseconds for commands which SDK sends over network (i.e. send message, join to a conversation, etc). Completion block will be called when timeout is reached.

In case of bad connectivity SDK retries to send command until timeout is reached. Timeout could occur earlier than specified time if there is no enough time to make one more attempt.

Value must be between TCHCommandTimeoutMin and TCHCommandTimeoutMax.

Default value is TCHCommandTimeoutDefault.

  synchronizeOnStartup

If set to true, the SDK will fetch all user conversations from the backend on startup.

@property (nonatomic, readwrite) BOOL synchronizeOnStartup

Discussion

If set to true, the SDK will fetch all user conversations from the backend on startup.

If set to false the SDK will start faster, but the myConversations property will return empty list and TwilioConversationsClientDelegate’s synchronizationStatusUpdated will be called with TCHClientSynchronizationStatusSynchronizationDisabled.

When set to false call conversationWithSidOrUniqueName to fetch specific conversation or call synchronizeConversations and wait for TwilioConversationsClientDelegate’s synchronizationStatusUpdated with TCHClientSynchronizationStatusCompleted to get all user conversations.

The default value is true.

  deferCertificateTrustToPlatform

Defer certificate trust decisions to the OS, overriding the default of certificate pinning for Twilio back-end connections.

@property (nonatomic, readwrite) BOOL deferCertificateTrustToPlatform

Discussion

Defer certificate trust decisions to the OS, overriding the default of certificate pinning for Twilio back-end connections.

Twilio client SDKs utilize certificate pinning to prevent man-in-the-middle attacks against your connections to our services. Customers in certain very specific environments may need to opt-out of this if custom certificate authorities must be allowed to intentionally intercept communications for security or policy reasons.

Setting this property to true for a Conversations Client instance will defer to iOS to establish whether or not a given connection is providing valid and trusted TLS certificates.

Keeping this property at its default value of false allows the Twilio client SDK to determine trust when communicating with our servers.

The default value is false.
